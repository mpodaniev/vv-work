# VV Work

## Stack

Vite + React + TypeScript (strict) + Tailwind CSS + Vitest + Testing Library + ESLint + Prettier.

## Getting started

```bash
npm install
npm run dev         # local dev server
npm run build        # production build
npm run preview      # preview production build
npm run test          # unit tests (Vitest)
npm run lint
npm run typecheck
npm run format
```
